贝克兰德纪事 · 隐私政策

更新日期：2026 年 9 月 6 日 · 生效日期：2026 年 9 月 6 日

《诡秘之主：贝克兰德纪事》（以下简称「本游戏」）是一款单机运行的 AI 文字冒险沙盒。我们按「最小化收集」原则设计：本游戏没有账号体系、没有服务器端存档、不主动收集任何个人身份信息。本政策说明游戏运行中涉及的数据及其去向。

一、我们处理的数据

  • 游戏存档：角色、物品、剧情进度等仅保存在你设备浏览器的 LocalStorage（网页版）或应用私有目录（安卓版）中，不会上传到我们的服务器——我们也没有用于接收存档的服务器。
  • API Key：你在设置中填写的大模型 API Key 默认仅保存在当前会话（sessionStorage）；只有你主动开启「跨会话保存」时才会写入本设备的本地存储。API Key 绝不会被写入游戏存档或导出的存档文件。
  • 导出的存档文件：由你主动导出，保存在你选择的位置，由你自行管理。

二、对话内容的去向（请重点阅读）

本游戏的剧情由你自行配置的第三方大语言模型服务生成。每次行动时，你的输入、必要的剧情上下文和游戏状态会通过网络请求发送给你所选择的服务商（如 OpenAI、DeepSeek、Google Gemini、OpenRouter，或你本机运行的 Ollama）。

  • 该请求由你的设备直接发往对应服务商，不经过本游戏作者的任何中转服务器。
  • 这些服务商对请求内容的保存与使用受其各自隐私政策约束，请在填写 API Key 前查阅对应服务商的政策。
  • 选择本机 Ollama 等本地模型时，对话内容不离开你的设备。

三、网络与权限

  • 网络访问：仅用于调用你配置的模型接口、检查应用更新（访问 GitHub Releases 及备用清单）与下载更新包。
  • 本游戏不申请通讯录、定位、相册、麦克风等敏感权限，不包含广告 SDK，不嵌入第三方统计或行为追踪组件。

四、未成年人

本游戏不向未成年人定向收集任何信息。由于剧情由第三方大模型实时生成，内容存在不确定性，建议未成年人在监护人陪同下游玩。

五、你的控制权

  • 清除浏览器站点数据或卸载应用即可删除全部本地存档与设置；游戏内也提供存档删除功能。
  • 你可以随时更换、删除已保存的 API Key，或完全使用无需联网的 Mock 模式体验核心流程。

六、政策变更与联系我们

本政策如有更新，将在本页面公布并更新顶部日期。如对本政策或数据处理有疑问，请通过 GitHub Issues 联系：github.com/Bemyself001/backlund-chronicle/issues。
