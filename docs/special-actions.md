# 特殊行动首版

## 玩家入口

底部第六项“特殊行动”按途径和序列显示工作、配方、身份登记与近期结算。
占卜师协会、静眠墓地、永恒烈阳教堂和圣赛缪尔教堂也有地图入口。
需要地点的工作必须实际到达；菜单中的地图按钮仅定位，不会免费移动。

## 内容范围

- 21类途径工作，每类3则固定剧情，各有两种处理方式，共63则。
- 歌颂者额外有3则永恒烈阳教堂仪式。
- 药师有外伤药膏、安神药剂、恢复药剂三张配方；前两张序列9开放，恢复药剂序列8开放。
- 通识者序列7开放普通手枪制作；只有普通装备属性，无非凡效果，也不包含现实制作步骤。
- 所有22条途径可到圣赛缪尔教堂明确确认加入值夜者，已在其他正式组织的角色不会被静默改换组织。
- 收尸人需先到静眠墓地登记守墓人。
- 魔女会按家传怀表终章已确认事实提供不同联络文本，不改写结局，不授予正式魔女会成员身份。

首版提供生计循环；没有新增魔药消化值，也没有为所有高序列编写专门工作。

## 经济与回合

- 同时一份委托。接单消耗1回合、5分钟；完成消耗1回合、30分钟。
- 结算或放弃后需经过3回合才能再次接单，所有工作共享间隔。
- 候选每3回合按存档种子抽取；不会与刚接过的同类剧情连续重复。接单后保存固定剧情和选项。
- 普通委托基础报酬9—24便士；每晋升一级增加2便士，额外部分最多12便士。
- 拳场完整竞技结局损失2点生命；部分地下委托选项降低工作声誉。界面预先显示。
- 小赌预留6便士；45%净赚6便士、20%打平、35%损失6便士。接单时固定结果，重开菜单和读档不会重掷；选择不下注或放弃退回预留金额，仍消耗回合及接单间隔。
- 材料购买、出售与用药各1回合、5分钟；制作1回合、30分钟。
- 外伤药膏：成本6、售价12便士，恢复2生命。
- 安神药剂：成本8、售价15便士，恢复1理智。
- 恢复药剂：成本12、售价20便士，恢复1灵性。
- 普通手枪：成本96、售价120便士，重量1.2kg。
- 制作检查行囊负重。属性满时不消耗药剂；装备中的物品不能出售。
- 持续状态与普通回合一样结算，所以本轮总属性变化可能与药剂的单次恢复量不同。

## 实现边界

- 内容：`src/content/backlund/specialActions.js`，通过内容注册表暴露。
- 规则：`src/engine/specialActions.js`，校验途径、序列、地点、身份、资金、材料与请求版本。
- 历史与审计：`src/services/specialActions.js`，写入故事、长期记忆待整理事件和回合摘要。
- UI：`src/components/SpecialActions.jsx`，复用游戏面板，也能通过地图弹窗打开。
- 存档新增可选的`specialActions`字段，旧档按需补默认值；内容版本更新并保留迁移链。
- 完成和取消清空当前委托并递增请求版本。旧请求、重复选择与已经售出的成品无法重复结算。
- 生产成品仅能在特殊行动里使用，普通物品工具会给出引导；普通药剂不带晋升魔药字段。
- AI上下文只包含当前委托的公开正文、身份和声誉，不包含赌博结果或未选择的结局。

## 验证

215项测试、ESLint、Vite生产构建通过。浏览器验证了观众接单、选择、收款、接单间隔与地图定位；检查320px、390px手机宽度和1440px桌面布局，无页面脚本错误。
