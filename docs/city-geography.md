# 城区图与原著依据

本地图是游戏示意图。原著提供城区、地标归属及部分相邻关系，没有覆盖所有地点的精确测绘坐标。格距、区界形状、桥位和河湾由游戏统一规划，不宣称为官方地图；多个工厂片区合并显示为「工厂区」。

本图采用北上南下，河流自西边进入，沿城中河湾向东流出并偏向东南，与用户要求的东西向河道一致。北岸包括皇后、北、西、希尔斯顿、乔伍德、东、工厂、码头和桥区；南岸的大桥南区位于西南侧，圣乔治区位于东南侧、与北岸码头区隔塔索克河相望。2026-10-06 按用户指出的区位关系对调原先放反的南岸两区，南岸货栈与圣希尔兰大教堂随所属城区迁移；大桥南端仍接入大桥南区。这些区域的精确边界、面积比例与方位角属于游戏布局，后续考据应优先校正区域关系，不将社区地图的坐标视为原著定论。

灰墙公寓、档案馆、雾鸦旅店、雷纳德宅邸、南岸货栈、东区火车站、装卸工广场、军情九处公开联络署及烈阳教堂等为游戏地点。地图以「游戏地点」区分；教会、博物馆等真实地标的本地服务和开局事件仍是游戏创作。东区车站不代表原著中央站。南岸货栈迁至大桥南区，保留原任务与地点 ID。

## 统一空间规则

- `content/backlund/geography.js` 保存可序列化的区界、河流格链和桥梁；不随角色随机种子改变。
- `system/mapGeometry.js` 统一地图坐标与轴坐标转换、城区归属、合法落点和过桥寻路。预览与实际旅行都使用相同路径，耗时为起步6分钟加每格7分钟；内部区域的出入为3分钟。
- `system/map.js` 唯一分配动态地标坐标。活动地标不重叠、不落水、不离开所属城区；内部地点共用父地标坐标，归档地点不占用新的活动格。
- `system/hexworld.js` 只让随机种子改变陆地街景；移动与探索不能把河面当成道路。区划、水系、大桥属于公开地理，未确认的地点名称仍隐藏。
- 当前只把贝克兰德大桥登记为可通行的跨河设施。渡船和其他通道若后续开放，必须同时接入几何、寻路与展示。

地图版本3、内容版本2026.10.06.3。地点 ID 不变，尤其保留 `queen-library`、`bridge-docks` 和 `machinery-heart`。旧档按登记位置重建地标，清除旧坐标的重复标记，当前玩家随地标迁移。版本2旧档的南岸动态地点随所属城区重新落点，内部地点跟随父地标，北岸合法坐标与有意跨区的锚点连接保留。普通探索格保持合法坐标并刷新城区；如果落在河道或范围外，则移到最近的陆地。旧档中某区地标过多时，将多出的地点保留为同区锚点的内部区域，继续保留 ID、知识状态与任务引用，避免丢档；新建地点遇到区内容量不足时明确拒绝登记。历史剧情、资金、物品和回合不重置；任务可用指引与当前记忆修正地名，已完成的历史不重新开启。
