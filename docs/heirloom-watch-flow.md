# 家传怀表调查流程（2026-09-16）

内容版本：2026.09.16.1。此处记录实际实现，旧终局历史不重写，进行中的任务刷新定义但保留阶段、事实和已领取奖励。

## 主线

1. 四次检查怀表：刻痕、记号与整点迟滞、隔板、纸条与失踪舅舅的回忆。
2. 去皇后区公共图书馆或希尔斯顿商会街解读纸条。钟表行由模型生成并通过 `location.grow` 登记后沿用，所在地条件接受商会街下的内部地点。
3. 追查舅舅旧档，实际抵达南岸货栈，听到小姐坠落号外。寻找排水道铁栅，向工人询问拆除承包商和失踪男孩。
4. 常规入口需完成求医和雷管支线，再次调查时发现官方先遣人员撬开的入口；起初不透露其身份。门途径可用能力提前进入，侦察后离开或蹲守一小时至交接。
5. 处理炸弹，找到舅舅，确认被强制晋升为考古学家；实际交谈、唤醒和展示怀表后，判断现有手段无法救回。
6. 让他解脱必须明确选择；仅提到舅舅、拒绝或犹豫不得误触。拒绝后可做一次救援尝试，进入明确的两次行动窗口。
7. 窗口内可夺枪限制、撤离或改变决定。窗口结束进入夹攻，角色能力和伤势由现有战斗工具结算，不设置自动死亡或自动获救。生命归零不能领奖或逃脱。
8. 官方按自身计划介入，组织身份与人情帮助接应，不保证保命。官方后续是否击退白鸢尾与玩家无关。铜哨、账册必须搜查取得；特性只在舅舅死亡分支产生。

## 三条支线

- 高窗之下：药师直接治疗；非药师接受引荐赴当晚20点拍卖会。固定药师埃德蒙·维尔交谈后，两人受邀去子爵包厢约定合作，平分20镑。也可用4镑购药，自己救治得20镑。购药可选，没钱可合作。治疗或交谈获得深度控制知识，药师主角自己表达那段感慨。
- 没有响的雷管：调查调包、追查去向、拆除；获得2镑、工具包和雷管知识。
- 退潮后的铁门：河岸入口与货栈支路分开。进入后有十次行动，救人一回合；每回合只能搜一类财物或推进救援，撤离一回合。可先搜后救、救后继续搜。现金480便士，碎金估值720便士，宝石估值600便士，总计7镑10苏勒；另有少量待鉴定材料，估值不直接增加资金。重复搜查不再发物品。第十次行动可以撤离，结算后仍未离开则任务失败。

## 计时与边界

- 计时器保存在任务实例上，开始后不会因搜查、阶段切换、读档或同回合重试而重置。
- 手记展示当前指引与剩余次数；打开面板不结算行动。真正提交一个回合，即使任务工具被拒绝，也会消耗正在进行的危险窗口。
- 未进入排水道前、未开始舅舅警告前，不开启对应计时。
- 特性、铜哨、账册、药剂、支线财物均采用稳定奖励ID，跨阶段共享同一领取记录。
- 1332、整点异常与送表者的最终身份尚未定稿；不能在当前阶段由模型提前编造成已确认答案。
- 完整自由叙事依赖已配置的AI；离线演示仍为现有有限演示，不等价于整条任务的离线剧情。
